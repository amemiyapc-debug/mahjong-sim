## 4. 判断に迷った点・実装で決めた点

- **⑦⑧の定義**(見込みが「要確認」): ⑦=音×(音・喘ぎ声)を、順序のない組で108、⑧=感情・状況×(感情・状況・態度)を77と数えた。「(状況・態度)」を、「感情・誘い」の全体から命令5語を除いたもの、と読んだ(除外条件⑧と同じ結果)。AとBの分類が重なる型(⑦⑧⑩)は、(A,B)と(B,A)を同じ組として1つに数えた。
- ⑧の「元の表の数」は不明。除外前の私の数え方は112(命令を含める)。
- ①の「男性器」「女性器」は、`words_ichishuu100.csv` の部位語の sub 列(男性器4語・女性器7語)。つがい(sub=番)は、全型で除外。
- ②のくり舐めは「おまめ・ぬれくり」の語を明示(部位名がくり=女性器の語のうち、設定ファイルに書かれた2語)。ちん舐め・ちんコキ=男性器4語、まん舐め=女性器7語、ぱいコキ=胸5語。
- ③の説明文は、2040の訂正(「Aが原因でBになること」)を `phrase_types.csv` に反映した。④は原文のまま。
- 句の数え方(分け方の和集合か、1つの分け方か)は、私が置いた定義。和集合は、1つの分け方では同時に表示できない句を含むので、(b)(c)では2つの値の差が大きい。
- ⑤⑥の語の選び方は、依頼どおり企画側の案のまま。`data/phrase_type_rules.csv` の行を直せば、差し替えられる。

## 5. 既存の指示・実装との食い違い(直していない)

- **「句」の意味が2つある**: CLAUDE.md §1-2・0910・2030 の「句」は、語A+語Bの組(看板・型)。一方、dan6 の段階クリア・点の式(`goro14.py`・試作HTML)の「句」は、語呂度のつながり(句ボーナス・「句を作る」条件)で、別のもの。2030 の「点数は同じ」「看板30組が従来どおり」は、前者の句の点を指すが、前者の句には、まだ点の式がない。

## 6. 図鑑(20261008-2040)との食い違い(実装していない。報告のみ)

- 現状の図鑑(`prototype/hiragana_tap_prototype.html` の「淫語集」と「語の図鑑(役割ごと)」)には、**句(看板・型)のページも記録もない**。保存は、語(`hm-proto-seen-words`)と、アガリの1行(`hm-proto-ingo`)だけ。句の保存(順序なしの2語の組、看板か型か、いつ作ったか)を、新しく持つ必要がある。
- 現状の語の図鑑は、役割ごとに「n/総数」「あと◯語」を出す(未入手の総数が見える)。2040・1320の「未入手は非表示(???もなし)」「n/130を出すか未決」と食い違う。句のページを足す前に、語の図鑑の総数表示の扱いを決める必要がある。
- 現状の図鑑は、新しい順に並べるが、**件数の上限は40件**(淫語集のみ)。2040の「型のページの1画面の件数。新しい順、古いものは続きのページ」は、ページ送りの仕組みがなく、新規実装になる。件数の目安: 1,000試合で、(c)で出た句の種類は891種(型のページで最大は③の262種・④の219種・②の188種)。
- 看板の名前の出し分け(1周目=リナ曰く、エンディング後=正名、3周目以降=A+B)には、周回の状態が必要。試作には周回の状態がない(ステージ番号で研究♡が決まる仕組みのまま。0845の「周回で上がる」と食い違うことは、前回報告済み)。
- 型のページは9つ。type_id は 1〜8 と 10(9・11は欠番)なので、ページの並び順は type_id の昇順にするのが素直。空の型ページ(まだ句を作っていない型)は、非表示にするか、空のまま出すかが未決。未入手を伏せる方針(語の図鑑と同じ)に合わせるなら、非表示。
- 型の表示は「型の説明文にAとBの語を当てはめる」ので、`phrase_types.csv` の description は、AとBを置き換える雛形として使える(「AをBに」など)。ただし、③④のように説明文が文型として不自然なもの(2040で③は訂正済み、④は書き直し予定)は、そのままでは表示に使えない。
