■決定事項
1. ×2牌を追加(新牌は他に採用しない)。語幹2枚+×2牌で1語(例: ちんちん)。×2語は62語。はしごでは×2語の語幹を同じ語幹とみなす(ちん×2とちんぽ=ちん語2つ)。山の×2は13枚(12/14は比較条件)。不要でツモ切りされてもよい。
2. 判定は並び順に依存せず、牌の多重集合で語が決まる。gen.py に全語(×2語・前置き語含む)の牌多重集合の重複チェックを入れ、つ=っ を同一視して検査する。重複があれば失敗させる。
3. ちゅ→つ/っ の代替ルールは廃止。つ=っ の互換は残す。プロトタイプの okTile にある ちゅ→つ 処理を削除。
4. 前置き(修飾語だけの面子)は100→58語(案B)。modifier_triples_B.csv を使う。
5. 7スロット(完成した一行の語順であり、語を並べる順):
   0 前置き → 1 感情・誘い → 2 部位 → 3 行為 → 4 音 → 5 反応 → 6 喘ぎ声 → (雀頭)
   スロット内の並び(暫定): 感情・誘い = 感情・状況 → 命令・誘い → 態度 / 行為 = 行為 → キス・吸い(キス・吸いは行為に統合) / 反応 = 高まり → 絶頂・結末(絶頂は反応に統合)
   旧スロットから移行し、CSVの slot_no/sub を使う。
6. 牌の枚数ルール: 枚数 = ceil(語での使用数/2)、最小2、最大10。修飾牌は +round(MODX × 前置き語での需要)。ぉ゛ = 4、×2 = 13。MODX は 0.1 を基準にし、0.05 と 0 も比較する(山の目安: 345 / 337 / 327)。
7. 牌の色: 完成した面子の牌はスロット別のパステル色、未完成の牌は白。
   前置き #E6E1EA / 感情・誘い #FFB8D4 / 部位 #FFD3C2 / 行為 #F0A0DC / 音 #BFD4FF / 反応 #CDB0F5 / 喘ぎ声 #FFF0A6
   14牌を 21×30px・隙間なしで 320px幅に収める。
