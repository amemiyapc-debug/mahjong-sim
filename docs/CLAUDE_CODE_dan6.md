【Claude Code 依頼 dan6】新辞書(し牌・おしり系)+役の整理+ボーナス廃止 を1回でまとめて実装

■前提
- dan5-data の最新を取り込んでから始める。docs/CLAUDE_CODE_dan5.md の決定事項は継続。矛盾したら今回が優先。
- メモリ負荷を下げるため、作業は A→B→C の順に進め、各作業の終わりに3行で報告する。最終報告は15行以内。実行して確かめた数字だけ書き、確認できなかったことは「確認できなかった」と書く。既存のコードを作り直さず拡張する。

■決定事項(今回の追加)
1. 「はじめての語ボーナス」は廃止(dan5の決定事項8の未実施分)。試作HTMLの計算・表示(アガリ画面の+N翻、演出の「はじめての語」カード)・保存データを削除する。他の翻加算(裏読みボーナスなど)は残す。シミュレーターに同様の処理があれば外す。
2. MODX は 0.05 に固定。×2牌は13枚。
3. 「お」と「ぉ゛」は牌としては別だが、面子・搭子・雀頭を作るときは同じ牌として扱う(dan5での統合は正しい)。
4. 新しい牌「し」を1種追加(これ以上の新牌は採用しない)。枚数は既存ルール(ceil(使用語数/2)、最小2、最大10)。使う語が19語前後なので10枚になる見込み。実際の枚数は gen.py で計算して報告する。
5. 辞書は data/words_by_slot_v16.csv(308語)+ data/modifier_triples_B.csv(前置き58語)= 366語。v15 からの差分は、おっおっ・ぉ゛っぉ゛っ を統合したことと、24語の追加(おしり・しり♡・デカしり・エロしり・見せしり・ぬれしり・しり穴・しり舐め・しりコキ・しり媚び・しっぽ・うしろ・ぬれけつ・おけつ・ぱんっ・ぱんつ・ぱちん・ぬれあな・しつけ・しこしこ・しかる・しめしめ・しこり・しこる・しまる のうち該当分。source 列が「追加(し牌・尻)」「追加(し牌)」の行)。×2語は63語(しこしこ・しめしめ を含む)。
6. 雀頭(略称)に「しり」を追加: tiles し|り、type 略称、part 後ろ、stem しり。
7. 役は data/yaku_final_v2.csv(85種)にする。170種から削減。
   - 削除する役: data/yaku_consolidation_proposal_v1.csv の「削除案」の39種。
   - 1本化する役(語幹名・部位名・修飾牌名を変数にして1つの役にし、フレーバー文は差し替え式にする): 語幹好き(同語幹2語・1翻)、語幹に夢中(同語幹3語以上・2翻)、部位コンビ/トリオ/カルテット(同じ部位の語が2/3/4語以上・1/2/3翻)、雀頭一筋(雀頭が略称で同じ語幹の語が1語以上・2翻)、雀頭ぞっこん(同2語以上・3翻)、修飾牌三昧(同じ修飾牌を使う語が3語以上・2翻)。proposal の「統合:」列の役が、これらに置き換わる。
   - 新役: 繰り返し(×2語が2語以上・1翻)、連呼地獄(×2語が3語以上・3翻)。
   - しり語幹と「後ろ」の部位(けつ・しり系)は、語幹好き・語幹に夢中・部位コンビ等に自動で含める。
8. 合体役(36個)のうち9個を削除する: M003 相思相愛、M004 SMクラブ、M005 全身ショー、M006 ぶっかけご奉仕、M008 ねちっこい責め、M015 全身コース、M016 奥まで届いた、M017 羞恥調教、M034 くぽ尽くし。M001 初夜は、元の役から「子づくり」が消えるので、元の役を 本番|準備万端 の2つにし、翻は合体の既存規則で再計算する。残り27個の元の役がすべて新しい役の一覧に存在するか確認し、存在しないものは報告する(勝手に削除・変更しない)。

■作業
A. 辞書と牌: gen.py を v16 で再生成。牌の組み合わせの重複チェック(つ=っ、お=ぉ゛、×2語、前置き語を含む)、牌の枚数表(し・り・け・つ・ぽ・お を含む)、山の枚数(MODX 0.05、×2=13)を報告。
B. 役と画面: 役エンジンを yaku_final_v2.csv に合わせる(1本化・新役・削除・合体整理)。試作HTMLに反映する(辞書・し牌・雀頭しり・役・ボーナス廃止・色分け・320px幅の確認)。既存のテストを更新して全部通す。判定の照合(Pythonと試作HTML)を、可能なら再度行う。
C. シミュレーション: 条件は1つ(MODX 0.05、×2=13)、2,000ゲーム。報告項目: アガリ率、平均翻、各スロットの語がアガリ手に入る割合、後ろの部位語(けつ・しり系)の出現割合、役ごとの出現率の分布(出現率0%の役の数、0.1%未満、1%未満)と、残った出現率0.1%未満の役の一覧、合体の成立率、ステージ目標点の再提案(ボーナス廃止後)。
