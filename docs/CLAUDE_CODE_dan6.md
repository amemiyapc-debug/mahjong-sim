■決定事項
【辞書・牌】
1. 「はじめての語ボーナス」は廃止。試作HTMLの計算・表示・演出カード・保存データ、シミュレーターの処理をすべて削除。裏読みボーナスは残す。
2. MODX=0.05、×2牌13枚。「お」と「ぉ゛」は牌は別だが、面子・搭子・雀頭では同じ扱い。つ=っ も同じ扱い。ちゅ→つ の代替は廃止(dan5どおり)。
3. 新牌「し」を1種追加(これ以上の新牌なし)。枚数は ceil(使用語数/2)、最小2、最大10。実際の枚数は gen.py で計算して報告。
4. 辞書は data/words_by_slot_v16.csv(307語)+ data/modifier_triples_B.csv(前置き58語)= 365語。×2語は63語。雀頭の略称に「しり」を追加(tiles し|り、part 後ろ、stem しり)。
5. 7スロット: 0 前置き → 1 感情・誘い(感情・状況/命令・誘い/態度)→ 2 部位 → 3 行為(行為/キス・吸い)→ 4 音 → 5 反応(高まり/絶頂・結末)→ 6 喘ぎ声 → (雀頭)。判定は並び順に依存せず牌の多重集合。

【役の再定義】
6. 面子(語)が最小単位の役。1語だけで成立する役は点にならない「飾り」(12個。data/yaku_reclass_v1.csv の区分「飾り」)。役は2語の組み合わせ=「句」が基本。
7. 役一覧は data/yaku_final_v2.csv(87種)。区分は yaku_reclass_v1.csv(句56、連鎖3語9、連鎖4語1、全体型7、飾り12)。ぱっくり=部位語+開き系擬音の句(1翻)。どろっは削除。純愛(3翻)・理性崩壊(2翻)は雀頭+語の句。部位名・語幹名・修飾牌名を変数にした1本化の役は、そのまま変数式で実装。
8. 名前つき合体は17個(data/merge_final_v3.csv)。合体の翻は「元の翻の合計+1(小・中合体)/+2(大合体)」。初夜=本番+準備万端の中合体。元の役がすべて新しい一覧に存在するか確認し、無いものは報告(勝手に変更しない)。
9. 段階名: つながった語の数で 語(1)→句(2)→節(3)→文(4)→碑文(5)。

【語呂度・連鎖・点の式(goro3.py が参照実装)】
10. 語と語は、語呂が良いときだけつながる(つながらない組み合わせもある)。つながりの強さ = スロット対の基本値(goro.py の BASE)+ 部位一致+2(穴は女性器/後ろ/口と+1、部位が違えばつながらない)+ トーン一致+1(ラブ×SMはつながらない)+ 音韻(しりとり/頭韻/脚韻)+1、命令語の係り先(なめろ等→部位、いけっ等→反応、なけっ等→喘ぎ声)は基本3。しきい値3(並3・良4・絶妙5以上)。語のタグは data/word_tags_v1.csv(機械付与で目視確認していない。見て明らかにおかしいものは報告)。
11. 連鎖の数え方: 語を節、つながりを辺とするグラフ。同スロットでつながった語は1つのまとまりにまとめ、まとまりと外の語のつながりは1本として数える。連鎖数 = 各連結成分の Σ max(0, 辺数−1)。連鎖倍率 = Π_{k=1..連鎖数}(1+0.5k)(1→1.5, 2→3, 3→7.5, 4→22.5, 5→78.75, 6→315 …上限なし)。合体同士の合体(入れ子)も、この数え方で自然に扱う。
12. テーマ倍率: 同語幹(まめ・おまめ・すじ は くり の別名扱い。修飾牌は無視)または同テーマ(部位 / 感じる / ラブ / SM)の語がそろうと 3語×2、4語×4、5語×8。複合テーマ(2つのタグの語を合わせて数える。両方1語以上): くりでイく、まんでイく、ちんでイく、胸でイく、お尻でイく、口でイく、ラブキス、調教、命令調教、濡れ濡れ、見せつけ(goro3.py の COMP)。
13. 点 = 500 × 句ボーナス × 連鎖倍率 × テーマ倍率。句ボーナス = 1 + Σ(各つながりの強さ−2 を最大3で切る)。**最低点は500(何もつながらない手)。上限なし。** 積み点は500固定のまま残す(最終値は未決)。
14. 大きな点の表示: 万・億・兆・京…の単位で、320px幅に収まるように。ハイスコアを記録・表示する(試作HTMLにも入れる)。

【ステージ制(段階クリア型)】
15. 1ステージ=3ゲーム。クリア条件は「点」ではなく「つながりの段階」。ライフ3(失敗でライフ-1、同じステージをやり直し、0でゲームオーバー)。ノーテンは1ゲーム消費、アガリは1ゲーム消費、テンパイ流局は消費なし(dan5どおり)。
16. 条件(仮): 1=句を作る / 2=節を作る / 3=節でテーマ語3つ / 4=文を作る / 5=複合テーマ成立 / 6=文でテーマ語4つ / 7=碑文を作る(5語全部つながる)/ 8以降=碑文でテーマ語5つ(おまけ。点の自慢)。3ゲームのうちどこかで満たせばクリア。
17. 「研究♡」(旧・淫乱度)は3段階(第一=無知、第二=恥じらい、第三=自覚)。ステージ1〜2=第一、3〜5=第二、6以降=第三。段階が上がるほど語呂のしきい値が下がる(仮: 第一=4、第二=3、第三=2。測定して調整)。
