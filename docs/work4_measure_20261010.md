## E 見送りの期待値(研究♡1・2)
方針: 研究♡1は見送り2回・研究♡2は3回(1ステージで共有)。ステージ1(句=2語つながる)・ステージ2(節=3語)の挑戦を、各300回。「点が低ければ見送る」のしきい値は、確定したときのアガリ点の25・50・75%点。「seek」は、条件を満たさない手を見送る。見送ったあと完成しなければ、ノーテン扱い(0点・1ゲーム消費)。
(研究♡2・ステージ1の例。ほかは JSON)

| 方針 | ステージクリア率 | 挑戦あたりの解読点(平均) | 消費ゲームあたりのノーテン率 | 見送り失敗(1挑戦あたり) |
|---|---|---|---|---|
| 確定(見送らない) | 100.0% | 15,481,120 | 5.4% | 0 |
| 低ければ見送る(25%点 101,250 未満) | 99.3% | 16,202,473(+4.7%) | 15.3% | 0.11 |
| 同(50%点 354,375 未満) | 98.7% | 17,942,780(+15.9%) | 26.7% | 0.27 |
| 同(75%点 1,575,000 未満) | 98.0% | 22,886,816(+47.8%) | 35.8% | 0.45 |
| 条件を満たさなければ見送る | 100.0% | 15,481,120(変わらず) | 5.4% | 0 |

研究♡1・ステージ1(解読点 4,963 → 5,392 / 5,767 / 5,800)、ステージ2(5,427 → 5,833 / 6,173 / 6,198)も、同じ傾向(挑戦あたりの解読点 +7〜+17%、ステージ失敗 100% → 97〜99%)。
- **見送りが得になる条件(測定の範囲)**: 手の点が小さいうちに見送るほど、挑戦あたりの解読点は増える(しきい値を上げるほど増える。研究♡2で最大 +48%)。そのかわり、ノーテンが増える(5%台 → 15〜36%)。
- **見送りのリスクは軽い**: ステージ失敗は 100% → 98〜99%(最大でも−3ポイント)。強CPUでは、ステージ1・2の条件は1回のアガリでほぼ満たされるため、見送ってノーテンになっても、同じステージのやり直しで取り戻せる。テンパイ流局がゲームを消費しない規則のもとでは、**見送りが軽すぎる**(得になる側に偏る)結果。ステージの条件が厳しくなる3以降と、ライフの減りは測っていない。
- 測っていない: 残りツモ回数別の差(見送り可能なのは、残りツモがあるときだけ。回数別には分けていない)・弱いCPU・人のプレイ・ステージ3以降の条件・夜シーンなど点の使い道を含む価値。
