# 1周目のステージ条件(和了回数)の測定(20261010-1210)

条件(`data/stage_wins_lap1.csv`): ステージ1=3ゲームのうち1回以上和了 / ステージ2=2回以上 / ステージ3=2回以上。
規則: 1ステージ=3ゲーム、ライフ3。アガリ・ノーテンは1ゲーム消費、**テンパイ流局は消費しない**。必要回数に達した時点でクリア。3ゲーム使って届かなければライフ-1・同じステージをやり直し。ライフ0でゲームオーバー。
測定: 強CPU(hint)・一周版100語・残りツモ12・seed 20261008+i(i < 12,000)。試合を順に使い、1回の挑戦=ステージ1からステージ3クリアかゲームオーバーまで。再現: `python3 ichishuu/measure_stage_lap1.py 12000`(結果 `ichishuu/results_stage_lap1_20261010.json`)。

## 測った値
12,000試合: 和了 8,107(67.6%)/ テンパイ流局 3,386(28.2%)/ ノーテン 507(4.2%)。消費するゲーム(和了+ノーテン)あたりの和了率 94.1%。挑戦 1,613 回。

| ステージ | 条件 | 1回の挑戦のクリア率(測定) | 同(計算。独立・和了率94.1%) |
|---|---|---|---|
| 1 | 1回以上 | 100.0%(1,613回中1,613回) | 99.98% |
| 2 | 2回以上 | 98.8%(1,633回中1,613回) | 99.00% |
| 3 | 2回以上 | 98.8%(1,633回中1,613回) | 99.00% |

**ライフ3での脱落(ゲームオーバー)**: 測定 0 / 1,613 回(0.0%)。計算では約 0.0004%(= 約25万回に1回)。ステージ3までは、強CPUではほぼ脱落しない。

## 前回の簡易測定(96.8% / 75.8% / 31.3%)との違い
前回は「テンパイ流局を和了でないゲームに数え、3ゲームを固定で使う」簡易測定だった。ゲームの規則では、テンパイ流局はゲームを消費しないので、消費するゲームだけで見ると和了率は 94.1% になる。そのため、クリア率は大きく上がった。前回の値は規則と合わない(誤差ではなく数え方の違い)。

## 測っていないもの
- 強CPU以外(人のプレイ、弱いCPU)。1周目の和了しやすさは、プレイヤーが自分でアガリ形を作る腕に左右される。
- ステージ4以降(条件が未決)。1周目のステージ数も未決。
- 見送り(研究♡0は1回)を使った場合。測定は見送りなし。
- 積み点・焦らしプレイの影響(クリア率には関係しない)。
